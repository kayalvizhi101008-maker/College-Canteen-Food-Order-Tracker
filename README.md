
# College Canteen - Food Order Tracker

## Project Description
A Django application to manage college canteen food orders using Django ORM.

## Technologies Used
- Python
- Django
- SQLite
- Visual Studio Code

## Model
FoodOrder

## Fields
1. customer_name
2. food_item
3. quantity
4. price
5. is_delivered

## Database Operations
- Created FoodOrder model
- Inserted five food orders
- Verified records using Django ORM
- Registered FoodOrder in Django Admin

## How to Run

1. Install Django:
   pip install django

2. Apply migrations:
   python manage.py migrate

3. Start server:
   python manage.py runserver
